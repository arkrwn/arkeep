# cofferak brand assets

Every file here is generated from vector sources, so use the SVGs
wherever possible; the PNGs are pre-rendered at fixed sizes for places
that need a bitmap.

## Files

| File | Use |
|------|-----|
| `cofferak-logo.svg` | Primary logo (mark + wordmark) for light backgrounds |
| `cofferak-logo-dark.svg` | Same, for dark backgrounds (cream wordmark and dot) |
| `cofferak-mark.svg` | Mark only, transparent background |
| `cofferak-mark-dark.svg` | Mark only, for dark backgrounds |
| `cofferak-icon.svg` | App icon: mark on a cream rounded square |
| `cofferak-social.svg` | Social preview card (1280×640) |
| `favicon.ico` | Favicon, 16–256 px in one file |
| `apple-touch-icon.png` | 180×180 home-screen icon |
| `png/cofferak-logo-{512,1024,2048,4096}.png` | Logo, transparent |
| `png/cofferak-logo-dark-{512,1024,2048,4096}.png` | Dark-background logo, transparent |
| `png/cofferak-mark-{16…2048}.png` | Mark, transparent |
| `png/cofferak-icon-{180,192,512,1024}.png` | App icon (PWA / store sizes) |
| `png/cofferak-social-1280x640.png` | Upload as the GitHub repository's social preview |

## Colours

| Name | Hex |
|------|-----|
| Rust orange | `#C75126` |
| Forest green | `#264233` |
| Cream | `#F5E6C9` |

Keep clear space around the logo of at least the height of the dot, and
don't recolour, stretch or rearrange the mark and wordmark.
